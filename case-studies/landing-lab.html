Landing Lab

Independent portfolio project · React, TypeScript, design systems, accessibility

Overview

Landing Lab compares three directions for FlowPilot, a fictional project-management product. All variants share one content model, while layout, typography, colour and visual composition change. The lab makes the comparison reviewable instead of presenting a single polished screen without context.

What I focused on

  • A shared LandingPage component with variant tokens and variant-specific CSS.
  • Live embedded previews with responsive scaling, section selection and accessible text alternatives.
  • A ten-dimension evaluation rubric with evidence, trade-offs and computed WCAG contrast ratios.
  • Native disclosures, skip navigation, focus management, reduced-motion support and axe-core coverage.
  • GitHub Pages project-path routing, deep-link fallback and dependency-safe testing.

Review and boundaries

The project is a design experiment, not a scientific benchmark or client result. It has no users, analytics, backend or fabricated business metrics. The case study documents the limitations, the review process and what still needs a second designer, screen-reader and real-device check.

Technology

React 19, TypeScript, React Router, Vite, plain CSS tokens, Vitest, Testing Library and axe-core.
