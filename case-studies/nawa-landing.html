Nawa Bilingual Landing

Independent portfolio project · React, TypeScript, RTL/LTR, accessibility

Overview

Nawa is a bilingual English/Arabic landing page concept for a digital studio. The implementation treats direction as a layout system: navigation, cards, forms, spacing and directional visuals adapt through semantic document direction and logical CSS properties.

What I focused on

  • English and Modern Standard Arabic copy with correct lang and dir state.
  • Keyboard-accessible navigation, a native modal mobile drawer and reliable focus return.
  • Localized validation with an accessible error summary and field relationships.
  • Localized titles, descriptions, canonical and alternate metadata, plus a restrictive production CSP.
  • Stable project-path asset loading and GitHub Pages deployment.

Review and boundaries

The project was reviewed with unit tests, Chromium E2E checks, axe accessibility scans, RTL/LTR layout checks and dependency auditing. It is an independent concept, not client work, and the contact form intentionally makes no network request.

Technology

React 19, TypeScript, Vite, plain CSS, self-hosted fonts, Vitest, Testing Library, Playwright and axe-core.
