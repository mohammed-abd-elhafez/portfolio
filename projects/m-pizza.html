M Pizza Arabic-first ordering platform

A pizza ordering system built Arabic-first: customer app, staff web tool and live order tracking.

Try the live demo Read the code

Platforms

The problem

A pizza business needed one connected flow for customers, staff and delivery updates instead of disconnected ordering and fulfilment tools.

What I did

  1. Product flow

    Mapped the customer ordering journey, staff workflow and live order states around the needs of an Arabic-first product.

  2. Interface

    Designed a clear mobile ordering experience and a focused staff workspace with status-driven interactions.

  3. Build

    Implemented a Flutter customer app with a Node.js TypeScript Fastify API, PostgreSQL and staff web tooling.

Where it stands

The customer ordering flow is live in Arabic, from the menu to checkout. The repository holds the Flutter app, the Fastify API with PostgreSQL and the staff web tool.
