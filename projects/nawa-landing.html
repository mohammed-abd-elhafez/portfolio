Nawa Bilingual RTL Landing Page

A bilingual landing experience designed for Arabic-first communication and accessible direction switching.

Live project · GitHub repository

Role
UX/UI design and frontend development
Platforms
Web
Year
2026

Problem

A bilingual product needs more than translated strings: hierarchy, alignment, navigation and focus behavior must remain clear in both directions.

Process

  1. Structure

    Organized the landing page around a concise value proposition, proof points and clear conversion paths.

  2. RTL system

    Built the layout and content structure to support Arabic RTL alongside English without duplicating the page.

  3. Build

    Implemented the responsive interface with React, TypeScript and Vite, with accessibility considered in the interaction model.

Result

A polished bilingual landing page is available for review with a clear responsive structure and RTL-aware presentation.

Stack
